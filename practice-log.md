# practice log

The cross-cutting record — every session, any instrument, plus composition,
recording, and production work. Newest first. The most honest file in the repo:
what you *actually* did, not what you meant to.

Per-instrument detail can live in each instrument's own log; this is the single
timeline that shows where the hours really went.
