# composition

Writing music. Where riffs grow up: song sketches, chord progressions, arrangement
notes, lyrics, form. A riff is a sentence; a composition is the paragraph that
decides what the sentence was for.

One file per song or sketch. There's no required shape, but most pieces want some
of: the core progression, the form (verse/chorus/bridge or whatever it actually
is), an instrumentation plan, lyrics or a melodic idea, and a note on what it's
reaching for. Link back to `riffs/` when a piece is built from one.

Half-finished is the normal state of a file here. Leave it mid-thought — a marked
gap is more useful than a forced ending.
