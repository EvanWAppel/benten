# riffs — the riff library

The offcuts drawer. Short musical ideas caught before they evaporate: a lick, a
phrase, a two-bar hook, a chord move that surprised you. Most will stay offcuts.
One of them will turn out to be the neck of something later — that's the whole
reason the drawer exists.

## How to file a riff

One file per riff, or group a batch into a dated file — whatever gets it captured
fastest. Speed beats tidiness here. A minimal entry:

```
## <name or first-line description>
- instrument: guitar
- key / tuning: E minor, standard
- tempo/feel: ~90 bpm, dragging
- capture: [voice memo link, or tab/notation below, or "hum it — see 2026-08-01 recording"]
- notes: what it's for, where it might go
```

Notation can be tab, chord names, a screenshot, or a pointer to an audio file — use
whatever loses the least of the idea. The riff you don't write down is the one you
spend next month trying to remember.
