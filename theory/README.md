# theory

Music theory as it's actually being learned — not a textbook, a set of working
notes. Theory is spell-check for the ear: it doesn't write the music, it tells you
when something you already felt has a name and a reason.

Keep one file per concept once it earns its own page. Suggested starting drawers:

- `intervals.md` — the atoms; how far apart two notes sit and what that distance feels like.
- `scales-and-modes.md` — the palettes.
- `harmony.md` — chords, voice leading, functional progressions.
- `rhythm.md` — meter, subdivision, feel.

Tie theory back to the instruments — when a concept clicks on the fretboard or the
keys, link it from the relevant `instruments/` note. The point is the connection,
not the vocabulary.
