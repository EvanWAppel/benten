# mandolin

Standing reference for mandolin. Default tuning: **G D A E** — same as a violin,
in fifths, in doubled courses. Those fifths are the whole personality of the
instrument: chord shapes and scale fingerings are unlike anything on a
guitar-family neck, so this drawer earns its own notes fast.
