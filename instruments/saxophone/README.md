# saxophone

Standing reference for saxophone. Note which horn you're on — **alto (E♭)** or
**tenor (B♭)** most likely — because it's a transposing instrument: your written C
is not concert C, and that has to be front-of-mind when playing with the piano or
guitar.

The only monophonic instrument in the collection, and the one that hides nothing:
no chord shape to grab, no frets to find the note for you. You have to *hear* the
line and support it with breath. That makes it the best ear-trainer of the six.

Drawers to fill:

- **Tone & breath** — embouchure, air support, long tones.
- **Transposition** — E♭/B♭ ↔ concert, worked out so it's automatic.
- **Scales & articulation** — the vocabulary of the line.
