# guitar

Standing reference for guitar. Default tuning: **E A D G B E** (standard) — note
alternates (Drop D, DADGAD, open tunings) as you use them.

Drawers to fill as they earn it:

- **Technique** — picking, fretting, barre chords, bends, whatever's under the microscope right now.
- **Chords & voicings** — shapes worth keeping, and where they came from.
- **Songs in progress** — what you're learning, and the bar that's fighting you.
- **Goals** — the next concrete thing you want to be able to play.

Practice record lives in [`practice-log.md`](./practice-log.md). Riffs go to the
shared [`../../riffs`](../../riffs) library, not here.
