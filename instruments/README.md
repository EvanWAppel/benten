# instruments

One drawer per instrument. Each holds a `README.md` for standing reference
(tunings, technique notes, songs in progress, goals) and a `practice-log.md` for
the running record of what actually got played.

- [guitar](./guitar) · [piano](./piano) · [ukulele](./ukulele) · [mandolin](./mandolin) · [bass](./bass) · [saxophone](./saxophone)

The instruments talk to each other. A chord shape learned on guitar reframes what
the piano is doing; the bass teaches the harmony from underneath; the saxophone
forces you to actually hear a line rather than grab it by shape. When a lesson on
one carries to another, note it — those crossings are where the theory in
[`../theory`](../theory) stops being abstract.
