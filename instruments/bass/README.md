# bass

Standing reference for bass. Default tuning: **E A D G** (standard 4-string) — note
if you're on a 5-string (add low B) or drop tuning.

The bass teaches harmony from underneath. It's the instrument that decides which
note a chord is really sitting on, and where the groove actually lives — so its
notes lean less on chord shapes and more on lines, root movement, and feel.

Drawers to fill:

- **Groove & feel** — locking with the kick, note length, ghost notes.
- **Lines & root movement** — walking, arpeggiated, how the low end drives harmony.
- **Technique** — fingerstyle, pick, slap if you go there.
